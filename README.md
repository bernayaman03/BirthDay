# BirthDay – Days Since Birth Calculator

A simple Android application developed using **Kotlin** and **XML layouts** as part of a mobile application development assignment.

The application calculates the number of days between a user-entered birth date and the current date.

## Features

- Accepts day, month, and year as separate inputs.
- Calculates the elapsed number of days using LocalDate and ChronoUnit.DAYS.
- Handles leap years and varying month lengths through the Java Date and Time API.
- Displays the calculated result on the screen.
- Shows an error message for invalid date inputs.

## Technologies

- Kotlin
- Android SDK
- XML Layouts
- Java Date and Time API
- Android Studio
- Gradle

## Project Information

This project was developed as an academic assignment to practice date calculations, user input handling, and Android UI development.
